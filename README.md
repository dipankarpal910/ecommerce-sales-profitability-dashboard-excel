# E-Commerce Sales & Profitability Dashboard - Excel

## Overview
This project analyzes 6500+ e-commerce orders to understand sales performance, profitability, delivery delays, and customer returns. The entire analysis is done in MS Excel.

## What I Did
- Cleaned 6500+ rows of raw data: TRIM, Remove Duplicates, TEXT formula for month/year
- Used Formulas: VLOOKUP/XLOOKUP, IF, SUMIF, COUNTIF, SUM, TEXT
- Applied Conditional Formatting for Late Delivery and High Profit orders
- Created Pivot Tables and Charts for KPI tracking
- Built a final Dashboard

## KPIs Tracked
- Total Sales & Total Profit
- Late Delivery %
- Return Rate
- Top Cities & Payment Methods

## Tools Used
Microsoft Excel - Formulas, Pivot Table, Conditional Formatting, Charts & Dashboard

## Key Insights
- Maximum orders from Kolkata, Bengaluru & Mumbai
- COD orders have the highest return rate
- Loyal customers generate the highest profit
